GSCA

Generalized structured component analysis with cSEM: a component-based alternative to PLS-SEM with a global optimisation criterion and overall fit indices.

On this page
  1. Getting your data in
  2. Practical demonstration: estimating the model with GSCA

Step by step

  1. Draw the model, or duplicate a PLS-SEM analysis as GSCA.
  2. Click Run GSCA to estimate and bootstrap the model.
  3. Read FIT, AFIT and GFI, then the weights, loadings and paths.

What you get

  • FIT, adjusted FIT (AFIT), GFI and SRMR
  • Weights, loadings and path coefficients with bootstrap intervals

Getting your data in

This analysis uses the project dataset. If the project has no data yet, upload a file on the Data tab (drop it there or click Choose file). If the project already has data, they are used at once.

  1. Draw the model from the indicators, or duplicate a PLS-SEM analysis as GSCA to use the same model.

Practical demonstration: estimating the model with GSCA

This example estimates the technology adoption model of the PLS-SEM page (six constructs, six paths) with generalized structured component analysis (GSCA). Like PLS-SEM, GSCA builds each construct as a weighted component of its indicators, but it fits the whole model with one overall criterion, so it also reports overall model fit.

Step 1. Duplicate the PLS-SEM model as GSCA

  1. Right-click the tab of the PLS-SEM analysis and choose Duplicate as GSCA.
  2. A new tab opens with the same constructs, indicators and paths. Nothing has to be drawn again.

To start from scratch instead, create a GSCA analysis with the + button of the Analyses list, load the data and draw the model as in PLS-SEM.

Step 2. Run GSCA and check the model fit

Click Run. GSCA uses 500 bootstrap samples by default (seed 2026, so the results can be repeated). Rows with a missing answer are left out (listwise): here 312 of the 320 respondents are used, as the Model check in the Properties panel warns.

IndexMeaningIn the example
FITShare of the variance of all indicators and components explained (0 to 1)0.526
AFITFIT adjusted for model complexity; use it to compare models0.523
GFI0.93 or more suggests good fit0.910
SRMR0.08 or less suggests good fit0.049

The model explains 53% of the variance of all variables. SRMR shows good fit; GFI is a little below 0.93 (Cho et al., 2020), so the fit is acceptable rather than good. FIT and AFIT have no cut-offs: use them to compare models estimated on the same data.

Step 3. Check the measurement model

Open the Measurement tab. It lists the weight and the loading of every indicator with bootstrap standard errors, p values and confidence intervals; the reliability (alpha, rho C) and AVE of each construct follow below the table.

  • Five reflective constructs are reliable and valid: rho C 0.873 to 0.915 and AVE 0.655 to 0.782 (thresholds 0.70 and 0.50).
  • Almost every loading is above 0.70; PE2 (0.669) and SI1 (0.698) are just below and can be kept, because their constructs are reliable.
  • Facilitating Conditions is formative (Mode B): judge it by its weights. FC1 (weight 0.327, p = 0.152) and FC3 (0.247, p = 0.199) are not significant; keep them if theory says they belong to the construct.

Step 4. Read the structural paths

Open the Structural tab. Each path has its coefficient, bootstrap standard error, p value and 95% confidence interval; the R² of each endogenous construct follows.

Five of the six paths are significant; only Effort Expectancy → Behavioural Intention is not (its interval includes zero). The model explains 13% of the variance of performance expectancy, 20% of behavioural intention and 23% of use behaviour.

Step 5. Compare with PLS-SEM and CB-SEM

GSCA and PLS-SEM agree on every path: both treat Facilitating Conditions as a composite, and both find its effect on use behaviour significant. CB-SEM, which forces it into a common factor, does not (p = 0.061). All three methods find no direct effect of effort expectancy on behavioural intention.

When the methods agree, the conclusion does not depend on the estimator. When they differ, look at how the construct is defined (composite or common factor) before choosing.

Step 6. Report the results

Open the Report tab of the GSCA analysis for the complete report, the R code and the references. Typical sentences, written from the example:

The model was estimated with GSCA (n = 312, listwise; 500 bootstrap samples). It explained 52.6% of the total variance (FIT = .526, AFIT = .523); SRMR = .049 indicated good fit and GFI = .910 was slightly below .93 (Cho et al., 2020).

Effort expectancy predicted performance expectancy (b = .37, 95% CI [.27, .48]), which predicted behavioural intention (b = .39, [.28, .50]); behavioural intention (b = .40, [.31, .50]) and facilitating conditions (b = .25, [.16, .36]) predicted use behaviour.

Good to know

  • Compare GSCA and PLS-SEM results on the same model as a robustness check.

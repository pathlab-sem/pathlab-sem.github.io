Latent profiles

Find groups of respondents with similar answer patterns: latent profile analysis with tidyLPA and mclust, latent class analysis, transitions and growth models.

On this page
  1. Getting your data in
  2. Practical demonstration: finding groups of adopters
  3. Step 1. Prepare scale scores
  4. Step 2. Set up the analysis
  5. Step 3. Choose the number of profiles
  6. Step 4. Interpret and name the profiles
  7. Step 5. Compare the profiles on other variables
  8. Step 6. Report the results

Step by step

  1. Choose the profile indicators.
  2. Set the range of profiles to compare and the model types.
  3. Run the analysis and compare the solutions in the fit table.
  4. Pick a solution and save each respondent's profile as a new variable.

What you get

  • AIC, BIC, entropy and bootstrap likelihood ratio tests
  • Profile means, sizes and classification probabilities
  • Profile plots and class membership

Getting your data in

This analysis uses the project dataset. If the project has no data yet, upload a file on the Data tab (drop it there or click Choose file). If the project already has data, they are used at once.

  1. Move two or more continuous indicators, such as scale scores, into Profile indicators.
  2. Optionally add outcomes or covariates to compare the profiles on.

Respondents with missing values in the indicators are left out; the results say how many.

Practical demonstration: finding groups of adopters

This example asks whether the 320 respondents of the technology adoption sample fall into groups with different patterns of beliefs, and whether those groups differ in how much they actually use the technology. Latent profile analysis (LPA) finds the groups from the answers; nobody is assigned to a group by hand.

Step 1. Prepare scale scores

LPA works best with continuous indicators, so use scale scores rather than single 7-point items. Compute PE_mean, EE_mean, SI_mean, BI_mean and UB_mean with Compute in the Data tab, as in Step 2 of the Statistics demonstration. Computed variables can be used by every analysis of the project.

Statistics

Step 2. Set up the analysis

  1. Add a Latent profile analysis with the + button of the analysis tabs. Keep Profiles selected in the Model tab.
  2. Move PE_mean, EE_mean, SI_mean and BI_mean into Profile indicators. These form the profiles.
  3. Move UB_mean and age into Compare profiles on. They are compared across the profiles but do not form them.
  4. Keep the models 1 · EEI and 2 · VVI selected and set the number of profiles from 1 to 5. With Run automatically on, the 10 solutions are estimated at once (100 bootstrap samples for the BLRT).

Step 3. Choose the number of profiles

The Model fit table lists every solution. Lower BIC is better; entropy and the average posterior probabilities show how clearly respondents are classified; the smallest profile should not be tiny; the BLRT tests k profiles against k − 1.

PathLab recommends model 1 with 2 profiles (analytic hierarchy process), and BIC agrees: it is lowest for 2 profiles and rises after. Two profiles fit better than one (BLRT p = 0.010). Every average posterior probability is at least 0.80, but entropy is only 0.55: the two profiles overlap, so treat individual memberships with care.

Entropy of 0.80 or more indicates a clear classification. With lower entropy, compare the profiles with the three-step (BCH) results of Step 5, which correct for classification error.

Step 4. Interpret and name the profiles

The Profiles section plots the mean of each indicator in each profile. Profile 1 (188 respondents, 60%) scores 3.7 to 4.1 on every belief; profile 2 (127 respondents, 40%) scores 4.7 to 5.1. The lines run in parallel, so the profiles differ in level rather than shape: call them moderate and enthusiastic adopters.

Save profile membership adds each respondent's profile as a new variable, ready for the Statistics analyses (for example a chi-square test with gender).

Step 5. Compare the profiles on other variables

The Comparisons section tests the variables you put in Compare profiles on. Enthusiastic adopters use the technology more: use behaviour 4.61 against 4.04, Welch F(1, 268.9) = 18.91, p < 0.001, η² = 0.057. Age does not differ (42.2 against 41.9 years, p = 0.806).

The three-step (BCH) analysis below corrects for classification error and confirms the difference in use: 4.71 against 3.93, Wald χ²(1) = 19.04, p < 0.001. Report these corrected values when entropy is low, as here.

Step 6. Report the results

Switch from Results to Report for the full report: method, fit table, profile sizes and means, comparisons and references. Download saves it; Edit text in the Edit tab lets you edit it in place.

Latent profile analysis of four scale scores (tidyLPA; n = 315) supported two profiles (BIC = 3919.04; BLRT p = .010; entropy = .55): moderate adopters (60%) and enthusiastic adopters (40%), who scored about one point higher on every belief.

Enthusiastic adopters reported more use of the technology than moderate adopters (BCH-corrected means 4.71 vs 3.93), Wald χ²(1) = 19.04, p < .001; the profiles did not differ in age.

Good to know

  • Entropy above 0.80 indicates a clear classification.

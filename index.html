What you can do

From path diagram to publication tables

Every analysis follows the same steps: load the data, draw or pick the model, run it, and export a report with the references already listed.

PLS-SEM

Draw constructs and paths on a canvas

Drag indicators onto constructs, connect them, and press Run. Reliability, validity (HTMT), path coefficients, bootstrapping, NCA, IPMA and PLSpredict appear in tabs below the diagram, and the diagram itself shows the estimates.

0.382BI → Use, β
8.855t value
< 0.001p value

Estimated by seminr 2.5.0

Statistics

Descriptives to survival analysis, from one ribbon

T-tests, ANOVA, regression, factor analysis, time series, power and more. Not sure which test? The “Which test?” guide asks about your data and opens the right one.

Computed by the jmv engine, the same one jamovi uses

Qualitative comparative analysis

Find the combinations that lead to an outcome

Draw conditions and an outcome, calibrate, and read the truth table and solutions. Robustness checks and predictive validity run alongside.

0.70PRI consistency

Computed by QCA (Dușa, 2019)

Bibliometrics

Map a literature from Scopus or Web of Science

Annual production, sources, authors, co-word and collaboration networks, thematic maps and a PRISMA flow diagram, in one workspace.

Built on R

Every number comes from a published R package

PathLab never estimates anything in the browser. It hands your model to R, and the report cites each package with the version you ran.

  1. 1

    You draw the model

    Constructs, indicators and paths on the canvas. Nothing is estimated in the browser.

    Private. Your data stay on your computer.
  2. 2
    > pls_model <- estimate_pls(data, …)
    > boot_model <- bootstrap_model(pls_model,
        nboot = 1000, seed = 2026)
    ✓ 1,000 bootstrap samples · seminr 2.5.0

    R does the maths

    Your model goes to R on your own computer, where the published packages estimate it.

    Checked. Tested against direct calls to each package.
  3. 3
    PathLab report.docx
    Referencesseminr 2.5.0 · R 4.4.3
    Rpathlab_model.R

    You get a report and the R script

    The report cites each package and version. The script recreates every number.

    Reproducible. Rerun it in any R session.

Getting started

Your first model in five steps

Follow along with the technology-adoption sample: 320 survey responses, six constructs, six paths.

Open the sample

Load the technology-adoption sample project. Its data and model open together.

Check the data

PathLab lists missing values and text columns before you start.

Draw constructs

Drag PE1–PE4 onto a new construct named Performance Expectancy.

Connect paths

Draw arrows between constructs. Each one is a hypothesis, H1 to H6.

Run and export

Press Run, read the results tabs, then export a Word report.
